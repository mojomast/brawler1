# Devplan

This folder is the persistent coordination surface for the OpenCode multi-agent workflow.

## Workflow

1. Plan the next focused slice.
2. Write or refresh a handoff in `devplan/handoffs/`.
3. Implement only the scoped slice.
4. Review and test.
5. Update `current-phase.md`, `progress-log.md`, and the next handoff.

## Current Rule

Milestone 1 is the active implementation boundary. Do not expand into dual protagonists, boss systems, or full stage content until the vertical slice is stable.
