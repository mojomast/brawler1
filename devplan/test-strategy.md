# Test Strategy

## Commands

- `npm run build`
- `npm run test`
- `npm run check`
- `npm run dev` for manual browser playtest.

## Manual Checks

- Start from title with `Enter`.
- Move with arrows or WASD.
- Jump with `Space`, dash with `Shift`.
- Attack with `J`, `K`, and `L` after meter fills.
- Confirm enemies chase, attack, take hitstun, and die.
- Confirm waves advance and win state appears.
- Confirm `P` pause and restart loops.
- Confirm enemy art does not look like player/polka-dot persona.
- Confirm `1` and `2` select different protagonists.
- Confirm all four stages progress in order.
- Confirm all three bosses spawn and escalate phases.
- Confirm final boss defeat reaches win state.
