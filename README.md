# Anti-Arena Prototype

Dependency-free browser Canvas prototype for a 2D belt-scroll beat 'em up with original theatrical papier-mache protagonists and satirical music-industry enemies.

## Run

- `npm run dev`
- Open `http://localhost:5173`

## Controls

- `Enter`: advance title/select or restart
- `1` / `2`: choose Khn or Klek on character select
- `Arrow keys` / `WASD`: move lanes and side-scroll
- `Space`: jump
- `Shift`: dash
- `J` / `Z`: light attack
- `K` / `X`: heavy attack
- `L` / `C`: special when meter is full
- `P`: pause

## Current Scope

Complete prototype pass: title, character select, Khn and Klek, regular enemy archetypes, four stages, three bosses, hit detection, health/special HUD, pause, win, lose, restart, generated geometric placeholder art.

The local theme music starts after the player begins a run, because browsers block autoplay before user interaction.
